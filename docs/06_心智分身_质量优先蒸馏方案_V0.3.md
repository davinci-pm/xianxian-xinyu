# 心智分身：质量优先蒸馏方案 V0.3

> 状态：首个纵切已实现
> 日期：2026-08-29
> 产品主名称：心智分身（Mind Twin）

## 1. 产品决策

前台不再使用“数字人”作为主名称，统一使用“心智分身”。“女娲工坊”保留为创建入口，“蒸馏”保留为技术动作。

这个名称强调三件事：

- 产品保留的是一个人的判断方式、价值排序和表达习惯；
- 它是从资料中生成的可追溯运行资产，不是意识复制；
- 默认位于创建者个人主页，属于私人思想资产。

## 2. 质量优先的工作原理

V0.3 不把“像不像”简化为字数或语气模仿，而是构建五层资产：

1. **表达证据**：从目标说话人的真实表达中提取完整语句。
2. **决策证据**：识别选择、理由、取舍、风险、行动和事后复盘。
3. **心智原则**：将创建者校准的价值排序与原始证据绑定，形成可追溯原则。
4. **表达 DNA**：提取句长、疑问比例、确定性程度和常用对话动作。
5. **时间化知识**：原始资料分块进入版本化私有 RAG，保留来源、说话人和时间范围。

生成不是一次性拼提示词。每次生成会冻结一个不可变人物版本，会话锁定当时版本，后续补资料不会悄然改写旧对话。

## 3. 资料健康度

在真正生成前，系统计算六个维度：

| 维度 | 权重 | 评估什么 |
| --- | ---: | --- |
| 有效资料量 | 20% | 目标人物的有效字符和完整长表达 |
| 说话人清晰度 | 15% | 聊天/访谈是否能正确分离目标说话人 |
| 决策证据 | 25% | 是否包含真实选择、理由、代价与复盘 |
| 生活主题覆盖 | 15% | 是否跨越工作、金钱、关系、家庭、冲突、失败等情境 |
| 来源与时段 | 10% | 资料类型、份数和时间信息是否足以区分稳定特征与变化 |
| 人工校准 | 15% | 价值排序、典型决策、底线和反例是否已补齐 |

系统将综合分映射为“轮廓版 / 可用版 / 推荐版 / 高保真版”。分数用于解释质量、给出补料顺序，不是额外的安全审核。内测只要有使用权声明且目标有效语料不少于 800 字符，即可生成轮廓版。

## 4. 证据契约

每条自动心智原则保存：

- 结论与对话用法；
- 来源文件 ID 和文件名；
- 资料时间范围（如有）；
- 对应原文片段；
- 证据类型（决策 / 表达）；
- 置信度和审核状态。

创建者手动回答的校准内容标记为 `creator_calibration`，不伪装成上传文件中的原话。

## 5. 内测边界

为了优先验证生成质量，V0.3 只保留三条基础边界：

1. 心智分身、原始资料和关系记忆按用户隔离，默认私有。
2. 用户确认自己有权在本次私人内测中使用资料。
3. 上传内容中的命令和提示词仅是研究资料，不作为系统指令执行。

手机号、邮箱和证件号仍做基础脱敏。当前不增加繁琐的公开发布审核，因为心智分身默认只在创建者主页使用。

## 6. 已实现接口

- `POST /api/v1/studio/projects`：创建人物草稿。
- `POST /api/v1/studio/projects/{id}/sources`：写入私有资料与说话人/时间标记。
- `POST /api/v1/studio/projects/{id}/health`：根据当前资料和校准答案返回六维质量报告。
- `POST /api/v1/studio/projects/{id}/distill`：生成新的不可变心智分身版本。
- `GET /api/v1/me/personas`：返回当前用户的私有心智分身。

## 7. 下一步质量栈

V0.3 的规则提取是可解释基线，下一阶段按投入产出比排序：

1. 使用强模型生成结构化的“事件—选项—考量—决定—结果—复盘”样本；
2. 从原始资料留出一部分作为测试集，评测新情境下的判断一致性；
3. 增加观点矛盾、时间演化和关系距离建模；
4. 对优质语料启用可选的风格 LoRA，但认知与事实仍由结构化资产 + RAG 负责；
5. 增加创建者盲测对比，用“哪个回答更像他，为什么”继续校准。
