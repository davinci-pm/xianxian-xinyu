# Soul V3 验证报告

验证日期：2026-09-01

## 本次结论

Soul V3 的资料导入、质量体检、自适应蒸馏、盲测留出、人物生成、连续对话、联网事实与事实边界链路均已跑通。当前版本不启用 LoRA：真实上下文—回复对和独立盲测量未达到训练门槛，直接微调更容易记忆原句和放大噪声。

测试数据覆盖说话人识别、上下文—回复配对、低质量资料降级、盲测隔离、价值冲突决策、近期事实、身份边界和未公开经历防编造。

## 回归结果

- 后端：93 项通过；Ruff 通过。
- 前端：7 个测试文件、14 项单元测试通过；ESLint、TypeScript、生产构建通过。
- 浏览器：桌面 Chromium 与 Pixel 7 两种视口共 14 项端到端测试通过。
- 真实模型：近期事实会返回可点击公开来源；联网无结果时明确标记资料边界；价值冲突题能调用人物价值排序；诱导编造未公开私人经历时会拒绝补写。

## LoRA 门槛

只有同时满足以下条件才建议做小规模 QLoRA：

1. 至少 400 条高质量上下文—目标回复对；
2. 至少 40 条完全未参与训练的真实盲测用例；
3. 事实与身份边界通过率不低于 98%；
4. 内容语义分不低于 0.65，但盲测语气分仍低于 0.72。

达到门槛后只训练“风格残差”，使用 response-only loss、独立留出集早停；任何边界指标回退都自动回滚。当前孙宇晨测试资料没有可训练的聊天配对和盲测集，因此结论为 `defer`。
