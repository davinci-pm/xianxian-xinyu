# 先贤心语前端重构交付包

这个目录用于直接交给 Codex，在现有“先贤心语”前端仓库中完成视觉、交互与核心功能重构。

## 最快使用方法

1. 解压本交付包，将整个目录放到项目的 `docs/design/先贤心语-redesign/` 下。
2. 在 VS Code 中打开“先贤心语”前端项目根目录。
3. 把 `00-先贤心语-Codex前端重构执行总提示词.md` 上传或粘贴给 Codex。
4. 同时告诉 Codex：

   > 请先阅读 `docs/design/先贤心语-redesign/` 下全部文件和图片，再严格执行 `00-先贤心语-Codex前端重构执行总提示词.md`。先审计现有项目并输出实施计划，然后直接开始修改；不要只给建议。

5. 要求 Codex 每完成一个阶段都运行项目、截图对比参考图并自测，不要一次性改完却不验证。

## 文件说明

- `00-先贤心语-Codex前端重构执行总提示词.md`：核心交付，包含页面、文案、交互、技术方案、接口、状态和验收标准。
- `01-交互流程与页面状态.md`：完整用户链路、分支、异常状态和 Mermaid 流程图。
- `02-人物立绘与视觉素材生成提示词.md`：人物图片规格、统一性要求和可复用生成提示词。
- `03-竞品与视觉改版方案.md`：竞品研究和设计依据。
- `design-references/`：6 张目标高保真设计参考图。
- `current-screenshots/`：7 张当前粗糙页面截图，用于前后对照。

## 重要说明

- 高保真图是目标视觉参考，不是可以直接切图上线的页面。
- 禁止把整张设计图当成背景图，也不要从截图中裁人物图用于生产环境。
- 人物立绘需要作为独立资源接入，并记录来源、授权状态或 AI 生成说明。
- 现有仓库的实际技术栈不在本工作区，因此总提示词要求 Codex 先检查项目后再决定保留或渐进升级，不允许无意义推倒重写。
- 第一阶段允许使用 Mock API 把完整交互跑通，但代码结构必须可以无缝替换为真实接口。
