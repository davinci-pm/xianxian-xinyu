# 人物立绘与视觉素材生成提示词

## 生产要求

- 每个人物至少准备：`portrait-card` 3:4 卡牌立绘、`portrait-detail` 4:5 详情立绘、`avatar` 1:1 头像。
- 同一人物必须固定脸部结构、年龄、发型、胡须、服装、主色、光线方向和绘画介质。
- 立绘可以生动，但不做游戏角色稀有度、恋爱陪伴或二次元抽卡风格。
- 历史人物应尽量尊重可靠肖像、雕塑和服饰资料；资料不足时明确标记“艺术化想象”。
- 当代真人或争议人物需要额外进行肖像权、人格权和平台政策评估，不得暗示本人授权或本人发言。
- 输出 WebP/AVIF，保留高清 PNG 母版。卡牌建议 960×1280，详情建议 1200×1500，头像建议 512×512。
- 图片不得包含人物姓名、印章、UI、按钮或文字，文字由前端渲染。

## 统一母提示词

```text
用途：先贤心语网站的人物独立立绘资产，不是完整网页。

人物：{人物姓名}，{时代与地域}，{年龄与外貌锚点}。
服饰：参考{可靠服饰/肖像资料}，保持历史合理性；避免现代配饰。
神态：智慧、真实、有生活感、愿意倾听，同时保留人物自己的精神张力；不要商业微笑。
姿态：半身或四分之三身，手部自然，视线轻微朝向画面外的对话者。
风格：高品质半写实编辑插画，东方人文档案馆与博物馆人物图录气质，细腻织物、自然皮肤纹理、克制的绘画笔触；不是照片，不是动漫，不是游戏原画。
背景：暖米色宣纸与极淡的时代性纹样，人物轮廓清晰，背景元素不超过 15% 视觉权重。
光线：柔和侧光，暖色调，保留面部结构和眼神。
色彩：整体使用米纸、墨黑、旧金、低饱和人物专属色；与 #F4F0E6 页面背景协调。
构图：{3:4 卡牌 / 4:5 详情 / 1:1 头像}，人物完整位于安全区，四周保留裁切余量。
一致性：同一人物的脸型、五官比例、发型、胡须、服装款式、主色和年龄必须与角色锚点图完全一致。
禁止：任何文字、印章、UI、边框、水印、品牌标识、武器炫技、霓虹、赛博朋克、抽卡光效、二次元、过度磨皮、现代服装。
```

## 孔子

```text
人物：孔子，春秋时期鲁国思想家，约六十岁。
外貌锚点：宽额、略长脸、沉静而温暖的眼神、灰黑长须、头发向后束起；面部有自然年龄纹理。
服饰：深墨蓝与褐金色交领长袍，细密但克制的织纹，黑色头巾；参考先秦礼服意象但避免影视戏服夸张。
神态：愿意先听清处境，温和中带有对责任的认真追问。
背景纹样：极淡竹影、山水与竹简纹理。
```

## 尼采

```text
人物：弗里德里希·尼采，十九世纪德国哲学家，四十岁左右。
外貌锚点：浓密向两侧展开的标志性胡须、深陷而敏锐的眼神、短发整齐后梳；不要夸张漫画化。
服饰：深棕或炭黑十九世纪欧洲高领西装与马甲。
神态：直视问题、略带挑战感，但不是愤怒或反派表情。
背景纹样：低饱和山岩、手稿和细微闪电式笔触，只作弱装饰。
```

## 前端接入约定

```text
public/characters/{figureId}/card.webp
public/characters/{figureId}/detail.webp
public/characters/{figureId}/avatar.webp
public/characters/{figureId}/motif.svg
```

每个资源附带元数据：

```ts
type CharacterAssetMeta = {
  figureId: string;
  assetType: 'card' | 'detail' | 'avatar' | 'motif';
  sourceType: 'public-domain' | 'licensed' | 'ai-generated' | 'artistic-reconstruction';
  sourceUrl?: string;
  license?: string;
  generatedAt?: string;
  promptVersion?: string;
  notes?: string;
};
```
